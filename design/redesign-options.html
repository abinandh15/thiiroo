Thiiroo dashboard — redesign options

What I found walking the app end to end with one sample order, and three directions for fixing it. All three share one visual language (larger type, bold colour-coded status tags, tight corners, one clear primary action) and keep the same flow: import → review → print → done. Photos and order numbers here are placeholders.

A · Pipeline

The current structure, made legible. The flow that used to hide in four sidebar sub-links becomes a strip of four stage cards with live counts. Click a stage to filter the list; every row carries its own next action.

Changes

  • Stage strip replaces sidebar sub-nav and the Overview stat tiles
  • Drop zone is the first stage, not a permanent 288 px rail
  • Row-level "Review" / "Print" buttons
  • Review: one approve button, checks instead of raw metadata

Keeps

  • Sidebar, per-product queues, keyboard shortcuts
  • Rows/cards toggle, batch select
  • All routes, so it can ship screen by screen
A1 · Product queuestages on top, filtered list below, next action on every row
A2 · Reviewsidebar collapses, bigger crop, buyer preview inset, checks instead of metadata, one primary action
A3 · Printsheets fill the canvas, one print button, preflight you can tick

B · Board

Closest to the reference you shared. One board for the whole shop: orders are cards with photo strips and coloured tags, columns are the stages. Review and print open on top of the board, so you never lose your place.

Changes

  • No sidebar. Products are filter chips
  • Inbox column holds the drop zone and unassigned orders
  • Review is a slide-over; print is a tray
  • Column-level actions: "Print all ready"

Trade-offs

  • Cards show fewer orders per screen than rows
  • Template editing and Add product move to a settings area
  • Drag between columns is tempting but must not bypass the review gate
B1 · Boardeverything in flight, across all products
B2 · Review slide-overopens from a card, board stays behind
B3 · Print traypick ready cards, sheets build up in the tray

C · Focus

Built for clearing the day in one sitting. A progress track across the top, the next job in the middle, a short "up next" list on the left. When review is empty the same space becomes the print step, then the import step.

Changes

  • Home, Queue, Review and Print collapse into one workbench
  • The primary button is always the next step, with its key
  • Printing ends with an inline "did it print OK?"
  • Empty state doubles as the import screen

Trade-offs

  • Less overview of older/printed orders (lives behind search and "All orders")
  • Largest change in how the app feels day to day
C1 · Review stepthe app opens straight into the first order that needs you
C2 · Print stepappears when nothing is left to review
C3 · All caught upempty state and import screen in one
